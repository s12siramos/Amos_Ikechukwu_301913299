# MIVA Care Clinic Management System

This portfolio demonstrates advanced database concepts using a simulated clinic.

## Case study

MIVA Care Clinic is a small-to-medium clinic that needs a reliable system for
patient registration, doctor management, appointment scheduling, diagnoses,
prescriptions, and laboratory results.

## Local database

PostgreSQL runs in Docker and is available on `localhost:5433`.

## Portfolio structure

- `portfolio-1-database-design/` — ER diagram, relational schema, constraints, and normalisation.
- `portfolio-2-query-optimisation/` — SQL queries, indexes, execution plans, and analysis.
- `portfolio-3-transactions-concurrency/` — transaction, rollback, isolation, and concurrency evidence.
- `portfolio-4-nosql/` — MongoDB model and implementation evidence.
- `portfolio-5-distributed-cloud/` — replication, availability, and cloud database discussion.
