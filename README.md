# MIVA Care Clinic Management System

This repository contains a complete advanced-database portfolio based on a fictional MIVA Care Clinic case study.

## Case study

MIVA Care Clinic is a small-to-medium clinic that requires a reliable system for patient registration, doctor management, appointment scheduling, diagnoses, prescriptions, laboratory results, and consultation records.

All records and names used in this portfolio are fictional and are included only for academic demonstration.

## Technologies

- PostgreSQL 16 in Docker
- MongoDB 8 in Docker
- MongoDB Atlas on AWS
- PowerShell
- SQL, JavaScript, Docker Compose, and GitHub

## Portfolio activities

| Portfolio | Focus | Evidence |
|---|---|---|
| Portfolio 1 | Database Design and Modelling | ER diagram, relational schema, keys, constraints, and normalisation |
| Portfolio 2 | Query Processing and Optimisation | SQL queries, benchmark data, execution plans, composite index, and performance analysis |
| Portfolio 3 | Transactions and Concurrency | COMMIT, ROLLBACK, row-level locking, and concurrent update evidence |
| Portfolio 4 | NoSQL and Advanced Data Models | MongoDB consultation documents, embedded records, queries, and indexing |
| Portfolio 5 | Distributed and Cloud Database | MongoDB Atlas deployment on AWS, three-node replica set, cloud data, and index evidence |

## Repository structure

- `portfolio-1-database-design/` - database design and relational schema.
- `portfolio-2-query-optimisation/` - SQL queries, indexing, execution plans, and analysis.
- `portfolio-3-transactions-concurrency/` - transaction and concurrency demonstrations.
- `portfolio-4-nosql/` - local MongoDB document model.
- `portfolio-5-distributed-cloud/` - MongoDB Atlas cloud and replica-set deployment.
- `portfolio-5-backup-recovery/` - additional PostgreSQL backup and restore verification.
- `final-documentation/` - final summary, reflection, references, and AI-use declaration.
