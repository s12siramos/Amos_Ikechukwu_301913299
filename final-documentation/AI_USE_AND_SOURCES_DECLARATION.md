\# AI Use and Sources Declaration



\## AI Use Declaration



AI tools were used to support learning, clarify database concepts, organise technical explanations, improve written documentation, and draft non-sensitive example content.



The student reviewed all generated material before use and remains responsible for the submitted work. All database commands, SQL scripts, Docker deployments, MongoDB Atlas configuration, screenshots, practical demonstrations, Git commits, and GitHub uploads were completed and verified by the student.



No real patient data, passwords, database connection strings, or confidential organisational information were provided to or included through AI tools.



\## Dataset Declaration



All patient names, doctor names, appointment records, consultation details, prescriptions, laboratory results, and benchmark records in this repository are fictional. They were created solely for academic demonstration. No real clinical or personal data is included.



\## Technologies and External Resources



\- PostgreSQL 16, used for relational modelling, SQL queries, transactions, optimisation, and backup verification.

\- MongoDB 8, used for local NoSQL consultation-document modelling.

\- MongoDB Atlas, used for the AWS-hosted distributed cloud database exercise.

\- Docker Desktop and Docker Compose, used to run local database services.

\- PowerShell, used to execute local commands and scripts.

\- Git and GitHub, used for version control and portfolio publication.
