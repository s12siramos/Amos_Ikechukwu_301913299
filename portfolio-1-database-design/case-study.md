# MIVA Care Clinic Management System — Case Study

## Organisation and system

MIVA Care Clinic is a simulated small-to-medium healthcare clinic. The clinic
requires a database system to replace disconnected paper files and support safe,
accurate day-to-day patient care.

## Users of the database

- **Receptionists** register patients and schedule appointments.
- **Doctors** view appointments, record diagnoses, and prescribe medication.
- **Laboratory staff** record requested tests and results.
- **Administrators** manage departments, doctors, and clinic reports.

## Main data stored

The system stores departments, doctors, patients, appointments, medical records,
medication details, prescriptions, laboratory test types, and laboratory test
requests/results.

## Main operations supported

1. Register a patient.
2. Add a doctor to a department.
3. Book, complete, cancel, or mark an appointment as no-show.
4. Record a diagnosis and clinical notes after an appointment.
5. Prescribe one or more medications for a medical record.
6. Request laboratory tests and record their results.
7. Retrieve a patient's appointment and medical history.
